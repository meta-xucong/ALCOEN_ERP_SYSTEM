# AI CATS 配件生产优化开发文档

## 目标

本次优化聚焦 AI CATS 的“配件生产”模块，在不改变现有主流程视觉风格的前提下，增加工件类型、外采质检材料、工件库存、订单历史记录，并保证旧数据默认归入“自产”逻辑。

## 范围

1. 工件库新增字段：
   - `workpiece_type`：工件类型，枚举值为 `self_produced`（自产）和 `outsourced`（外采）。
   - `stock_quantity`：库存数量，默认 `0`，由验收入库自动累加。
2. 工件订单新增字段：
   - `workpiece_type`：订单快照中的工件类型，创建订单时从工件库复制。
   - `inventory_posted_at`：该订单是否已完成入库的幂等标记。
3. 新增订单历史表：
   - `qc_work_order_histories` 记录订单创建、编辑、质控完成、质检提交、验收签字、入库、回退等关键行为。
4. 外采附件逻辑：
   - 自产：沿用原“图纸”单文件逻辑。
   - 外采：用“质检材料”替代“图纸”，支持不限数量动态上传。
   - 作业指导书、备注逻辑继续保留。
5. 质量检测逻辑：
   - 自产订单展示“图纸”检测项。
   - 外采订单展示多个“质检材料”检测项。
   - 作业指导书仍要求合格报告后才能勾选通过。
   - 质检材料作为原始质检输入资料，检测确认函可选，不额外强制上传合格报告。

## 数据模型

### `qc_workpieces`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `workpiece_type` | VARCHAR(20) | `self_produced` | 工件类型 |
| `stock_quantity` | FLOAT | `0` | 当前库存数量 |

### `qc_work_orders`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `workpiece_type` | VARCHAR(20) | `self_produced` | 工件类型快照 |
| `inventory_posted_at` | DATETIME | NULL | 已入库时间，非空表示该订单库存已入账 |

### `qc_work_order_histories`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER | 主键 |
| `work_order_id` | INTEGER | 关联工件订单 |
| `operator_id` | INTEGER | 操作人，可为空 |
| `action` | VARCHAR(100) | 行为标题 |
| `detail` | TEXT | 行为详情 |
| `created_at` | DATETIME | 操作时间 |

## 附件类型

| 附件类型 | 用途 |
| --- | --- |
| `drawing` | 自产工件图纸，单文件 |
| `qc_material` | 外采工件质检材料，多文件 |
| `inspection_point` / `instruction` | 作业指导书 |
| `remark` | 备注 |

## 流程设计

### 工件库

1. 新增/编辑工件时，基础信息增加“工件类型”下拉菜单。
2. 选择“自产”时显示图纸卡片。
3. 选择“外采”时显示质检材料卡片，允许动态增加/删除上传项。
4. 旧工件默认 `self_produced`，旧图纸逻辑不变。
5. 工件列表和详情页展示类型与库存数量。

### 工件订单

1. 新增/编辑工件订单基础信息中，“工件类型”放在“工件名称”前。
2. 工件下拉框按工件类型过滤。
3. 选择工件后，预览区域根据类型切换：
   - 自产：图纸卡片。
   - 外采：质检材料多文件卡片。
4. 创建订单时复制工件类型和附件快照，避免工件库后续修改影响历史订单。

### 质量检测

1. 质检明细按订单附件快照展示。
2. 外采订单的 `qc_material` 以“质检材料”展示，支持多项逐项检测。
3. UI 使用统一卡片/网格结构，避免多文件导致横向溢出或卡片错乱。

### 验收入库

1. 当订单最终进入 `accepted` 状态时：
   - 若订单有关联工件，且 `inventory_posted_at` 为空，则给工件库存增加 `order.quantity`。
   - 设置 `inventory_posted_at`，保证重复点击不会重复入库。
2. 如果已验收订单被回退：
   - 撤销本次订单入库量。
   - 清空 `inventory_posted_at`，后续重新验收时可再次入库。

### 历史记录

1. 历史记录不可编辑，不提供修改/删除入口。
2. 工件订单详情、质量检测详情和验收详情底部展示同一历史卡片。
3. 记录的关键事件：
   - 创建订单/保存草稿
   - 编辑订单
   - 完成质量控制
   - 保存/提交质量检测
   - 验收确认
   - 库存入库/撤销入库
   - 验收回退

## 验证清单

1. `py_compile` 检查修改的 Python 文件。
2. 数据库 `PRAGMA table_info` 检查新增列与历史表。
3. 工件库闭环：
   - 新增自产工件
   - 新增外采工件，多质检材料
   - 编辑并切换类型
4. 工件订单闭环：
   - 按类型筛选工件
   - 外采多质检材料预览不破版
   - 创建订单、质控完成、质检提交、验收完成
5. 验收入库：
   - 首次验收增加库存
   - 重复验收不重复增加
   - 验收回退撤销库存
6. 历史记录：
   - 关键事件按时间倒序/正序展示清晰
   - 不出现编辑入口
